# Selected public projects

A short guide to the technical work in this GitHub account. Each link points to source code and its own README; this is not a list of production deployments.

## Backend and data tooling

| Repository | What it contains |
| --- | --- |
| [DXQL](https://github.com/arpesterev/dxql) | Java library for executing XML-configured SQL queries, validating inputs and assembling results with Spring JDBC |
| [metan](https://github.com/arpesterev/metan) | Structured JSON-like data model, path resolution and configurable merge operations |
| [Telegram Support Library](https://github.com/arpesterev/telegram-support-library) | Telegram bot dispatchers, update handling and response models in Java |
| [GhostBuster](https://github.com/arpesterev/ghostbuster) | XML-based report layout models and a JasperReports integration |
| [Uncharted](https://github.com/arpesterev/uncharted) | React and TypeScript visualization components with grid layouts and generated API types |

## Reading these projects

The READMEs distinguish implemented code from unverified features and known limitations. Several repositories are historical exercises or prototypes, and some are forks of upstream open-source work. A repository's presence here does not mean it is a deployed or supported product.

The larger numerical-research repositories are private and are deliberately not listed. No confidential employer work is documented here.
